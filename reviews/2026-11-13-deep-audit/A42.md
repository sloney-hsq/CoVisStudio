# A42：工具与新前端契约

已读审查说明、设计摘要、AGENTS、README、TASKS、CONTRACT；核对 `backend/charts.py`、`revisions.py`、`category_sets.py`，追踪 `evidence_candidates.py`、指标元数据与前端格式化。仅静态审查及一次无查询的离线状态复现；未启服务、未调用 API、未验证真实模型/UI。

1. **P2／设计取舍：Save 与立即 Pin 必须分开。** 普通触发：用户在动态 Top N 图上点 “Keep this group”，再改地区。`save_category_set` 只存库（`category_sets.py:53–66`；`CONTRACT.md:92`），`keep_current` 保留排名规则（`revisions.py:61–63`、`CONTRACT.md:73`），两者都不会固定当前成员。若把此按钮接到上述动作，下一次重算仍会换成员。最小方案：Save 留作复用；Keep this group 以当前版本精确成员和明确目标立即应用，设置 categories、清空 top_n；复用 `use_evidence` 编译路径（`revisions.py:134–152`），不恢复旧范围或数值。

2. **P2／设计取舍：Linked views 应展开为明确 view_ids。** 普通触发：三图联动改地区，同时保留各自指标。现有原子 `edit_charts` 已逐图合并 source，未列出的图不变（`charts.py:75–100`）；`revise_analysis` 接同一编译器（`revisions.py:152`）。新 UI 只需明确联动组、把目标 ID 与本次地区/类别补丁传给共享工具；选图/高亮不能自行扩张目标或筛选。多个图各自 Top N 不等于共享同一组类别，固定比较须传同一精确成员。保留“分析修订／呈现编辑／集合保存应用”的职责，无需新增一套全局联动工具或提交权威。

3. **P3／代码缺陷：重复声明原指标也会改掉标题，修订卡却无变化。** `charts.py:94–95` 只判断 metric 键存在，未判断指标真的改变；`revisions.py:158–167` 只比较 source。离线复现：现有 orders 图标题 `Orders for the comparison group`，提交 `source_patch={"metric":"orders"}, member_action="keep_current"`；结果标题变成 `Orders`，source 不变、`changed_fields=[]`。建议只在指标实际改变且未显式传标题时刷新标题。真实指标切换的自动标题、数据重算和单位格式已存在（`charts.py:94–100`、`data.py:148`、`frontend/src/chart.js:13–18`），不应再把“单位未同步”列为当前缺陷。
